# Privacy and Publication Boundaries

[English](PUBLICATION.md) · [简体中文](PUBLICATION.zh-CN.md) · [README](README.md)

## Public Scope

Public material consists of repository documentation and translations, the MIT license, ignore rules, dependency specifications, project scripts and tests, templates, the distillation skill and its references, and the two original example directories.

The synthetic example contains a generated tone and colour blocks with explicit fixtures. The OCR example contains an original text-card video, original frames, and actual machine outputs—not font files.

System-generated speech audio and its full run directory are not distributed. Redistribution permission for that audio has not been established; only the test summary and self-recorded reproduction instructions are public.

## Excluded Material

Do not commit account records, browser profiles, cookies, API keys, tokens, private keys, SSH configurations, temporary signed URLs, private hosts or personal paths, private media, raw comments or commenter identities, old transcripts, research libraries, model weights, virtual environments, logs, caches, installers, or historical work products.

Captured `status.json` can contain temporary media URLs. Keep it and raw captures in a private processing directory. Public accessibility alone does not establish redistribution rights. Public examples must be original or separately cleared for redistribution.

## Before Publishing

Inspect the actual staged files and Git history, not only ignore rules. Check credential patterns, personal paths, account data, URL query parameters, images, and documentation. A scan with no matches establishes only that its rules found no matches.

Only the explicit task authorizes publication. Preparing files, accepting documentation, or choosing MIT does not authorize uploading unrelated or later-added material.
